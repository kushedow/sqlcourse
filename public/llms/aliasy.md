# Алиасы


## Алиасы: новые имена


`AS` позволяет называть колонки так, как нам нравится! ✨

Зачем это нужно?   Чтобы сделать названия понятнее, избежать конфликтов имен, или упростить работу с данными в приложении.

Представим таблицу **animals**:

| id | name | species | emoji |
| --- | --- | --- | --- |
| 1 | Buddy | Dog | 🐶 |
| 2 | Whiskers | Cat | 🐱 |
| 3 | Leo | Lion | 🦁 |

**Выберем имена, назвав колонку "animal_name":**

```sql
SELECT name AS animal_name FROM animals;
```

Результат:

```sql
animal_name
Buddy
Whiskers
Leo
```

**Выберем вид, назвав колонку "вид_зверя":**

```sql
SELECT species AS вид_зверя FROM animals;
```

Результат:

```sql
вид_зверя
Dog
Cat
Lion
```

### Важно:

AS не меняет структуру таблицы, а только название колонки в результате запроса.

Новое имя (алиас) может использоваться в других частях запроса (например, в ORDER BY)

Кавычки (одинарные или двойные, в зависимости от СУБД) могут понадобиться для алиасов, содержащих пробелы или специальные символы.
